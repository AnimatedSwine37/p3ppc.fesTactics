# p3ppc.fesTactics

A **WiP** mod for Persona 3 Portable PC that ports the tactics from Persona 3 FES.

I don't know whether I'll ever finish this but I'm uploading it so someone else can continue on if they want to. The code is three years old so I don't remember too well, but I believe the C# stuff is functional. It should add new tactics in the menu that can be selected. It seems the problem was the game was crashing when actually implementing those tactics due to some file size limit. Good luck if you try to work it out :D
